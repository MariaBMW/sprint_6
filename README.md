# sprint_6
Написание автотестов для учебного сервиса «Яндекс.Самокат» с применением Page Object Model и подключением Allure-отчёта.

## Тестовые сценарии
- Проверка открытия соответствующего текста ответа при нажатии на стрелочку вопроса в разделе "Вопросы о важном"
- Заказ самоката. Проверка всего флоу позитивного сценария с двумя наборами данных. Проверка точек входа в сценарий, их две: кнопка «Заказать» вверху страницы и внизу
-  Проверка перехода на соответствующие страницы при нажатии на логотипы

## Тесты
Написаны с применением Page Object Model, на Selenium, разделены по своей функциональности. Все тесты лежат в директории tests. Все тесты запускаются и имеют статус "passed".

## Установка
- виртуальное окружение: python3 -m venv .venv source .venv/bin/activate
- зависимости: pip install -r requirements.txt

## Запуск тестов
- запуск всех тестов: pytest -v
- запуск тестов в конкретном файле: pytest -v tests/название файла
- запуск тестов с формированием папки с отчетами в формате JSON: pytest tests --alluredir=allure-results
- формирование отчетов в формате веб-страницы: allure serve allure-results
